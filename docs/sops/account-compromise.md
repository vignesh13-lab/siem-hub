# Account Compromise Response

## Purpose
Steps to contain and investigate a suspected compromised account.

## Steps
1. Confirm the alert and identify the affected user and source IP.
2. Check recent logins and privilege changes for that user.
3. Reset credentials and revoke active sessions.
4. Isolate affected hosts if lateral movement is suspected.
5. Document findings in the ticket and close or escalate.

## Escalation
Escalate to the incident response lead if privileged access was involved.
