# SIEM Hub

Central library of detections, accelerators and SOPs.

## What's here
- **Detections**: SPL use cases with MITRE mapping and tuning notes
- **Accelerators**: ready-to-use content packs
- **SOPs**: step-by-step response procedures
- **Onboarding**: how to contribute

## How to contribute
Copy a template from `templates/`, add your page, and open a pull request.
